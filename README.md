# KI-Mail-Connector

Java-21-/Maven-Projekt für einen KI-gestützten Mail-Connector.

## Voraussetzungen

- JDK 21
- Maven 3.9+
- IntelliJ IDEA

## Start

```bash
mvn clean test
mvn exec:java -Dexec.mainClass=com.fourwt.mailconnector.KiMailConnectorApplication
```

In IntelliJ das Verzeichnis als Maven-Projekt öffnen.

## Status

Initiale Projektbasis. Fachliche Mail-Connector-Funktionalität ist noch nicht implementiert.
